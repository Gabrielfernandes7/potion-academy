# Glossário

Use sempre estes nomes, em qualquer tela, texto ou conversa.

| Nome na tela | Significa | Não use |
|---|---|---|
| OURO | a moeda do jogo (antes POÇÃO) | moedas, POÇÃO (não usar: é a poção) |
| FRASCO | um slot de bomba ativa; "+1 FRASCO" aumenta o limite | bomba (na tela) |
| Poção de Fogo / Aqua / Telúrica / Etérea | os 4 tipos de bomba | bomba normal, mega |
| GEMAS | as 3 gemas para abrir a porta | pedras |
| BLOCOS | caixotes destruídos (contador) | caixas |
| TEMPO | o tempo que sobra na fase | timer |
| VIDA | os corações | HP |
| Caldeirão de Magia | a loja | shop |
| Caixote | o bloco de madeira destrutível | bloco (na conversa) |
| Muralha | a parede de pedra indestrutível | parede |
| Porta | a saída, aberta com 3 gemas (no jardim, o **portão**) | saída |
| Roo | a personagem | canguru, bruxo (na tela) |
| Belladona | a bruxa chefe da fase 3 | vilã, bruxa má |
| Fase | cada etapa do jogo, com o nome do ato: 1 O CHAMADO, 2 O CAMINHO, 3 O DUELO, 4 O RETORNO | nível |
| Frei Anselmo | o monge que pede as escrituras de volta | padre, irmão |
| Carta | o texto de abertura, antes da primeira fase | mensagem, bilhete |
| Sapo mago / Fantasma / Flor do mal | os inimigos comuns | criatura, monstro |
| Neutralizar ("APAGADA") | a água desfazer uma poção de fogo em vapor | apagar, cancelar |
| Aviso | a marcação colorida no chão antes de um ataque | sombra, alvo |
| Furiosa | estado da Belladona com metade da vida ou menos | enraivecida |
| Ajuda | a janela "Como jogar" (botão ?) | tutorial |
